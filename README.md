# 從零開始學 Rust

為程式新手準備的 Rust 教學，從基本語法、所有權一路講到非同步程式設計。

- 網頁版：<https://holmeslin.github.io/learning-rust-from-zero/zh-TW/>
- 原始檔：<https://holmeslin.github.io/learning-rust-from-zero/zh-TW/rust-book-src.zip>

## 參考來源

本教學的原作者是 [Andy Shiue](https://github.com/AndyShiue)，原始專案為 [AndyShiue/learning-rust-from-zero](https://github.com/AndyShiue/learning-rust-from-zero)，原作者的網站是 <https://learning-rust-from-ze.ro/>。

本 repo 與原作者版本的差異：

- 移除英文版，只保留繁體中文版。
- 調整建置腳本、部署流程與說明文件，讓網站部署在本 repo 的 GitHub Pages。

教學內容（`zh-TW/src/`）與原作者版本相同，未做修改。想看英文版或最新內容，請前往原作者的專案。
